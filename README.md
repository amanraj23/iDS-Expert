# iDS Expert

Modern Next.js website for iDS Expert, an independent application assistance service for government jobs, competitive exams, admissions, scholarships, recruitment forms, and other online applications.

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the site.

## Environment

Copy `.env.example` to `.env.local` and configure:

```bash
MONGODB_URI=
AUTH_SECRET=
NEXT_PUBLIC_SITE_URL=
NEXT_PUBLIC_WHATSAPP_NUMBER=
NEXT_PUBLIC_PHONE_NUMBER=
```
